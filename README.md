# Vivant Skin Clinic

A premium, modern, and highly interactive healthcare website built for a skin aesthetics clinic.

Vivant Skin Clinic focuses on creating a luxurious digital experience with elegant UI design, smooth animations, responsive layouts, and a strong brand presence.

🌐 **Live Website:** https://vivantskinclinic.com

---

## 📌 Project Overview

Vivant Skin Clinic is a frontend-focused business website designed to showcase a professional skin clinic's services and create a premium online presence.

The project was developed with modern frontend technologies and inspired by high-quality award-winning website experiences.

The main focus of this project was:

* Premium user interface design
* Smooth animations and interactions
* Responsive user experience
* Modern frontend architecture
* Professional healthcare branding

# 🚀 Installation & Setup

## Clone Repository

```bash
git clone https://github.com/abubakarafzal0101/VivantSkinClinic.git
```

## Navigate to Project

```bash
cd VivantSkinClinic
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

The application will start on:

```
http://localhost:5173
```
